# SLink

SLink 是面向 Windows 10/11 x64 的原生便携 SSH/SFTP 桌面客户端。项目使用
C++20、Win32、Direct2D 和 DirectWrite 开发，不依赖 Qt、Electron、WebView，
目标是在较小体积和内存占用下提供终端、文件传输、远程编辑与端口转发能力。

## 功能概览

### SSH 终端

- 服务器列表支持实时搜索；双击服务器即可打开终端。
- 内置“本地主机”，双击后直接打开本机 CMD，不需要额外配置。
- 支持多标签终端。将单个标签拖到另一终端区域可创建左右分屏，将标签拖回另一
  分屏的标签栏可合并为多标签窗口。
- 支持 UTF-8、中文 IME、256 色/真彩色、鼠标协议、备用屏幕、Bracketed Paste、
  复制和 OSC 52 安全确认。
- 每个终端使用独立 SSH Channel，分屏尺寸变化会同步 PTY 大小。
- 网络会话每 60 秒执行一次保活；输入新命令时自动回到当前输入位置。
- 网络断开后在终端输入可重新建立普通 Shell；不会恢复断线前的远端进程或工作目录。

### 文件传输

- 初始显示本地主机桌面，本地主机标签固定保留；双击服务器可追加远程文件会话。
- 支持多标签及左右分屏，标签的拆分、移动与合并行为和终端页面一致。
- 本地和远程面板均支持路径输入、回车前往、刷新、鼠标侧键前进/回退。
- 隐藏文件默认不显示；本地快捷方式可解析目标，并显示与 Windows 桌面一致的图标。
- 文件列表显示名称、状态、大小、修改时间、权限和所有者；点击“名称”或
  “修改时间”表头可切换升序/降序，刷新目录后保留当前排序。
- 支持鼠标框选、拖放、复制、剪切、移动、删除、行内重命名、新建文件、
  新建文件夹及 UNIX 权限修改。
- 任意面板之间均可传输，包括本地上传、远程下载以及远程到远程内存中继；
  远程中继不会创建本地临时文件。
- 冲突发生时可选择覆盖、跳过或自动重命名，并可批量应用；支持断点续传和可选
  SHA-256 校验。
- 目录任务会展开显示文件级状态、进度、大小和实时速度；完成、失败或取消后速度
  显示为 `—`。
- “并发数”表示同时传输的文件数量，可在 1–8 之间调整。程序按服务器自动维护
  1–4 条传输专用 SFTP 连接，浏览、编辑和终端连接不占用该连接池。

### 文件编辑

- 使用和终端、文件传输一致的服务器列表；本地主机默认进入桌面，远程服务器默认
  进入登录用户主目录，也可在服务器配置中指定初始目录。
- 文件列表复用文件传输页面的自绘表格、文件图标、快捷方式解析和前进/回退行为。
- 路径右侧可刷新目录；文本标签底部可将保存编码切换为 UTF-8 或 GB2312。切换原始
  8 位文件时会先解码为 Unicode，无法用 GB2312 表示的字符会阻止保存并提示。
- 使用独立 `Scintilla.dll` 和 `Lexilla.dll`，支持多文件标签、语法高亮、行号、
  撤销、编码与 EOL 保留以及按内容出现的横向滚动条。
- 远程文件缓存在程序目录中；保存前重新检查远端大小、修改时间和内容摘要。
- 无冲突时上传同目录临时文件并原子替换；远端已变化时可查看差异、覆盖或另存为。
- 大于 20 MB 的文件默认只读；检测到二进制内容时使用只读十六进制预览。

### 端口转发

- 手动填写本地监听地址和目标服务器地址，不依赖已打开的终端会话。
- 输入端口或 `127.0.0.1:端口` 时仅监听本机回环地址；输入 `0.0.0.0:端口`
  时可向局域网开放。
- 每条转发规则可单独启停，配置和代理开关持久化到状态库。
- 防火墙功能由用户主动开启的管理员辅助进程处理。关闭辅助进程或退出 SLink 时，
  会删除本次运行创建的规则；异常退出遗留记录会在后续启动时清理。

### 主题与界面

- 设置页面提供深色和浅色主题，可运行时即时切换；终端背景会同步切换。
- 导航、侧栏、标签、表格、滚动条、按钮和拖放提示使用项目内置轻量自绘控件，
  避免不同 Windows 版本的 Explorer 主题差异。
- 文件列表和传输队列按可见行绘制，不为大目录中的每个项目创建 Win32 子窗口。
- 终端、文件面板、传输队列和编辑器区域均支持拖动分隔线调整大小；拖动期间只显示
  无残影参考线，松开后一次提交最终布局。

## 服务器与凭据

服务器管理界面支持单层分组：可新建、重命名和删除分组，并在新增或编辑服务器时
选择所属分组。终端、文件传输和远程编辑共用按组展开的服务器侧栏；搜索可匹配
服务器或分组名称，折叠状态会保存。删除分组只会把组内服务器移到“未分组”，
不会删除服务器配置或断开已有会话。

支持以下认证方式：

- 密码；
- 私钥及私钥口令；
- Windows OpenSSH Agent；
- Keyboard-interactive。

首次连接会要求确认主机指纹；已知主机密钥发生变化时会阻止连接。

应用不要求输入主密码。首次运行时会在 `data` 目录生成随机 `vault.key`，并使用它
自动解锁加密的 `vault.db`。`vault.key` 与 `vault.db` 必须一起保留；任何能够完整
读取便携目录的人也具备解密已保存凭据的条件，因此应像保护私钥一样保护该目录。

## 便携数据与隔离

SLink 使用 `GetModuleFileNameW()` 获取 EXE 所在目录，不依赖启动时的当前工作目录。
程序目录必须可写，否则应用会停止启动并给出提示。
构建完成时 `out/bin` 顶层仅有 `SLink.exe`、`Scintilla.dll` 和 `Lexilla.dll`；
下述 `data`、`cache`、`logs` 目录由程序运行时按需创建。

```text
SLink/
├─ SLink.exe
├─ Scintilla.dll
├─ Lexilla.dll
├─ data/
│  ├─ state.db
│  ├─ vault.db
│  ├─ vault.key
│  └─ known_hosts
├─ cache/
│  └─ editor/
└─ logs/
   └─ crash/
```

服务器配置、转发规则、传输恢复信息、编辑缓存和日志均位于 EXE 相对目录。应用不会
把内部数据写入 `%APPDATA%`、`%LOCALAPPDATA%`、`%TEMP%`、ProgramData、注册表
或 Windows 凭据管理器。用户主动选择的上传源和下载目标不受此限制。

## 源码结构

```text
.
├─ 3rd/
│  ├─ include/              # 编译所需的第三方头文件与许可证
│  ├─ lib/                  # x64 Release 静态库及编辑器 DLL
│  └─ libvterm/             # 参与构建的 libvterm 源码及许可证
├─ include/                 # 项目头文件，目录结构与 src 对应
├─ resources/               # Win32 资源、应用图标和 manifest
├─ src/                     # 项目实现
├─ build.ps1                # 构建入口
├─ CMakeLists.txt
└─ THIRD_PARTY_NOTICES.md
```

`3rd` 仅保存本项目构建需要的第三方头文件、静态库、`Scintilla.dll`、
`Lexilla.dll`、许可证，以及直接参与构建的 libvterm 源码；不包含包管理器
安装树或下载缓存。旧的预编译 `libvterm.lib` 未使用，因此未放入发布目录。
构建输出、便携数据库、凭据、缓存、日志和内部测试源码均不纳入仓库。

## 构建要求

- Windows 10/11 x64；
- Visual Studio 2022，并安装“使用 C++ 的桌面开发”；
- CMake 3.25 或更高版本，可直接使用 Visual Studio 自带版本。

不需要额外安装 Qt、vcpkg、Ninja、OpenSSL 或其他第三方 SDK。随项目提供的静态库
按 MSVC 2022 x64 Release `/MT` 构建。

## 构建

在项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\build.ps1 `
  -Configuration Release `
  -Clean
```

也可以直接执行：

```powershell
.\build.ps1 -Configuration Release
```

`out/build` 保存 CMake 缓存和调试符号；可交付的三个文件位于 `out/bin`。
`-Clean` 只清理 `out/build`，不会删除 `out/bin` 中的便携数据与凭据。
Windows 文件属性中的版本与设置页右上角的 `V1.1.1` 均来自 CMake 项目版本。
